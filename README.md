## 📘 About This Project

This repository contains detailed documentation about **Microsoft Azure Core Services**.

The guide explains what each Azure service is, how it works, why it is used, its advantages, limitations, best practices, and practical Azure CLI commands.

This documentation is created for beginners, students, and aspiring Cloud Engineers who want to understand Microsoft Azure cloud computing.
